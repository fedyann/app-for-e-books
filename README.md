# Живой учебник

Прототип цифрового учебника для школы: текст, аудио, видео и интерактивные задания в одном месте. Главная идея — материал, который можно не только прочитать, но и покрутить, послушать и разметить прямо в браузере.

## Демоверсии

Три предмета, каждый показывает свой набор форматов:

| Предмет | Что внутри |
|---|---|
| **Английский язык** (Focus 3) | аудирование, видеозадание, упражнения с чекбоксами и полями для ответов |
| **Геометрия** (10–11 класс) | 3D-модели куба и сферы, которые можно вращать |
| **Химия** (10 класс) | 3D-модели sp- и sp²-гибридизации с просмотром в AR |

## Возможности

**Живой поиск по странице.** Собственная реализация: обход текстовых узлов через `TreeWalker`, подсветка всех совпадений тегом `<mark>` и автоматическая прокрутка к первому найденному месту. Поиск не заходит внутрь служебных элементов и корректно снимает предыдущую подсветку, восстанавливая исходную структуру DOM.

**Маркер для конспектирования.** Выделяешь фрагмент текста, нажимаешь на цвет — фрагмент подсвечивается, как маркером в бумажном учебнике. Вложенные и пересекающиеся выделения разворачиваются корректно.

**3D-модели и AR.** Модели молекул и геометрических тел в формате `.glb`, встроенные через `<model-viewer>`. Вращаются мышью или пальцем, а на телефоне открываются в дополненной реальности — модель можно поставить на стол.

**Аудио и видео** подключены нативными тегами с `preload="none"`, без сторонних плееров и внешних сервисов.

## Стек

HTML, CSS, JavaScript без фреймворков. Единственная внешняя зависимость — [`<model-viewer>`](https://modelviewer.dev/) от Google, подключается по CDN.

## Структура

```
.
├── index.html          — лендинг проекта
├── books.html          — каталог демоверсий
├── english.html        — учебник английского
├── geometry.html       — учебник геометрии
├── chemistry.html      — учебник химии
└── source/
    ├── styles/         — стили: общие и по одному файлу на предмет
    ├── script/
    │   ├── search.js   — поиск и подсветка по странице
    │   └── script.js   — маркер выделения текста
    ├── models/         — 3D-модели .glb
    ├── audio/          — аудио для аудирования
    ├── video/          — видеозадания
    └── img/            — обложки и иллюстрации
```
